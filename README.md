# 我炒，冰！！！

一个使用 Python + Pygame 实现的“一箭又一箭”风格冰淇淋箭头解谜小游戏。

## 1. 游戏规则

- 棋盘为 5×5 网格，箭头有上、下、左、右四个方向。
- 点击箭头后，检查它前进方向与棋盘边界之间是否存在其他箭头。
- 没有阻挡：箭头飞出棋盘并消失。
- 有阻挡：箭头不能消失，播放晃动反馈并扣除一次失误次数。
- 清空当前关卡后进入通关界面，再进入下一关。
- 失误次数耗尽后失败，可以重新开始。
- `R`：游戏中重新开始；`M`：音乐开关；`Esc`：退出。

## 2. 开发环境

- Python 3.10+
- Pygame 2.6.1+
- Windows / macOS / Linux 均可运行；中文字体优先使用系统字体。

## 3. 安装与运行

```bash
python -m pip install -r requirements.txt
python main.py
```

Windows 也可以双击 `run_game.bat`。

## 5. AIGC 协作记录（根据本次真实开发过程整理）

### 子任务 1：界面贴图整合
- AIGC：ChatGPT / Codex
- 要求：根据自制 UI 图，把游戏界面改成冰淇淋主题，并尽量使用图片素材而不是纯色方块。
- AI 完成：整理游戏背景、开始/通关/失败/规则界面贴图，并把箭头素材用于 Pygame 绘制。
- 人工修改：根据实际运行窗口继续调整棋盘位置、按钮点击区域和素材尺寸。

### 子任务 2：路径检测与关卡设计
- AIGC：ChatGPT / Codex
- 要求：实现四方向路径检测，并设计至少 3 个实际可通关关卡。

- 人工修改：根据试玩结果调整关卡布局与箭头数量。

### 子任务 3：碰撞反馈、飞出动画和音乐
- AIGC：ChatGPT / Codex
